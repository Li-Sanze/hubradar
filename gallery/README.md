- `hubradar/`：HubRadar 自身的 3 分钟白皮书与分层矢量架构图（真实 Dogfood，基于固定提交 `93ef1e1`）。
- `honojs__hono/`：外部开源项目 Hono 固定提交 `5ca49b0720755c585c9a9835f0a479ceea36fb52` 的白皮书卡片、facts、宿主综合 JSON 与分层矢量架构图。
